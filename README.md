*🚨 CrisisGrid*



*AI-Powered Emergency Response \& Crisis Management Platform*



*CrisisGrid is an emergency response command center designed to help authorities and response teams report, analyze, prioritize, and manage crisis incidents from a centralized dashboard.*



*The platform combines a modern React dashboard with a Node.js/Express backend and SQLite database.*



*---*



*## 🎯 Problem*



*During emergencies, response teams often face:*



*- Delayed incident reporting*

*- Difficulty prioritizing multiple emergencies*

*- Poor coordination between response units*

*- Lack of centralized incident information*

*- Slow decision-making during critical situations*



*CrisisGrid provides a centralized system for managing emergency incidents and prioritizing response actions.*



*---*



*## 💡 Solution*



*CrisisGrid provides an emergency command dashboard where users can:*



*- 🚨 Report new incidents*

*- 🤖 Analyze incidents using risk-scoring logic*

*- 📊 Assign severity levels*

*- 📍 Track incident locations*

*- 👥 Record affected people*

*- 🚒 Generate recommended response actions*

*- 💾 Store incidents in a database*

*- ⚡ View priority emergencies in real time*



*---*



*## ✨ Features*



*### Emergency Dashboard*



*- Live incident overview*

*- Critical incident counter*

*- Active responder statistics*

*- Available response units*

*- Average response time*

*- Priority incident list*



*### Incident Reporting*



*Users can report:*



*- Industrial Fires*

*- Building Collapses*

*- Floods*

*- Road Accidents*

*- Medical Emergencies*

*- Chemical Leaks*

*- Other emergencies*



*Each report contains:*



*- Incident type*

*- Location*

*- Description*

*- Number of people affected*



*### AI Response Engine*



*The system analyzes incident information and generates:*



*- Severity classification*

*- Risk score*

*- Recommended response units*

*- Emergency actions*



*Example:*



*```text*

*Severity: CRITICAL*

*Risk Score: 94/100*



*Recommended Response:*

*🚒 Deploy 2 Fire Units*

*🚑 Dispatch 1 Ambulance*

*🏥 Alert nearest hospital*

*🚨 Establish emergency perimeter*
